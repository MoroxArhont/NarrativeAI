# NarrativeAI 3.1 — запуск и развёртывание

## Требования

- Node.js 20+ (рекомендуется Node.js 22 LTS) или Docker.
- Один Supabase-проект владельца приложения с применёнными миграциями.
- Для генерации: локальный Ollama/LM Studio либо OpenAI-совместимый API.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` — единый Supabase-проект владельца приложения.
- `APP_URL` — публичный HTTPS-адрес приложения. Для локальной разработки `http://localhost:3000`.
- `APP_ENCRYPTION_KEY` — 32 случайных байта в hex (64 символа). Сгенерировать: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.

Не меняйте `APP_ENCRYPTION_KEY` после сохранения пользовательских токенов и храните резервную копию. При утрате ключа сохранённые API-токены расшифровать нельзя.

## Миграции Supabase

Примените `supabase/migrations/20261117104714_fix_avatar_storage_select_policy.sql` и `supabase/migrations/20261120115509_add_encrypted_ai_api_keys.sql` в SQL Editor после базовой миграции v3.0. Пользователям не требуется создавать собственный Supabase: приложение использует один проект владельца, а RLS изолирует пользовательские записи.

Для подтверждения почты откройте Supabase Dashboard → Authentication → URL Configuration. Установите Site URL в значение `APP_URL` и добавьте его в Redirect URLs. Новые письма будут возвращать пользователя на домен приложения; локальная разработка использует localhost.

## Локальный запуск

```powershell
Copy-Item .env.example .env
npm install
npm start
```

## Docker

Из корня проекта:

```bash
docker compose -f deploy/docker-compose.yml up --build -d
```

Перед запуском заполните корневой `.env`. Остановка: `docker compose -f deploy/docker-compose.yml down`.

## Пользовательские AI-токены

В настройках ИИ пользователь может указать собственный OpenAI-совместимый API token, Base URL и модель, а затем проверить соединение. Ключ шифруется AES-256-GCM на сервере, хранится в пользовательской строке `user_settings` и никогда не возвращается клиенту. Пустое поле оставляет ранее сохранённый ключ без изменений; отдельный флажок удаляет его.

Старый `AI_API_KEY` остаётся необязательным серверным fallback. Не используйте его как общий ключ публичного сервиса, если хотите, чтобы каждый пользователь оплачивал свой API.

## Режиссёр и интерфейс

ИИ-режиссёр запускается по эвристике: на первом ходе, примерно раз в шесть ходов и при сообщениях с потенциально значимыми изменениями. Он анализирует последние шесть сообщений и факты истории. Это снижает число вызовов, но не гарантирует обнаружение всех несоответствий.

На компьютере боковая навигация закреплена, чат прокручивается отдельно. На мобильных устройствах диалог открывается отдельным экраном с кнопкой возврата.

## Проверки

```bash
node --check server.js

npm run format:check
npm run css:build
```

Для публичного развёртывания также проверьте подтверждение почты, регистрацию, генерацию через API, мобильную версию и изоляцию двух пользователей.
