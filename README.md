# NarrativeAI 3.0

Веб-приложение интерактивных историй с ИИ-режиссёром и ИИ-повествователем.

## Стек

- Node.js + Express
- Supabase Auth — регистрация, вход и сессии через access token
- Supabase PostgreSQL — профили, настройки ИИ и истории
- Supabase Storage — аватары, обложки и фоны чатов
- Row Level Security — пользователь видит и изменяет только собственные данные

## Запуск

1. Установите Node.js 20 или новее.
2. Скопируйте `.env.example` в `.env`.
3. Укажите `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` из настроек проекта Supabase.
4. Укажите `AI_API_KEY`, если используете внешний API-модель.
5. Выполните `npm install`, затем `npm start`.
6. Откройте `http://localhost:3000`.

SQL-схема находится в `supabase/migrations/`. Она должна быть применена к проекту Supabase до запуска приложения. В проекте NarrativeAI миграция `20261117094321_initial_narrative_schema` уже применена.

Если в Supabase включено подтверждение почты, после регистрации откройте письмо-подтверждение, затем войдите в приложение.

## Важно

- В браузер передаётся только publishable key и пользовательский access token; `service_role` / secret key не требуется.
- `.env` не добавляйте в Git и не публикуйте.
- SQLite больше не используется приложением. Старый файл `data/narrative.sqlite`, если он остался от предыдущей версии, автоматически не импортируется.
- Изображения хранятся в Supabase Storage; в PostgreSQL сохраняются только пути к файлам.

## Форматирование кода

В проект добавлен Prettier. После `npm install` можно отформатировать JavaScript, HTML, CSS, JSON, YAML и Markdown:

```bash
npm run format
```

Проверить форматирование без изменения файлов:

```bash
npm run format:check
```

В VS Code рекомендуется установить расширение **Prettier - Code formatter**. Для поддерживаемых файлов форматирование при сохранении включено в `.vscode/settings.json`.

## Развёртывание в отдельном репозитории

Конфигурация отдельного репозитория развёртывания подготовлена в каталоге `NarrativeAI-deploy` (отдельный архив). Основной репозиторий собирает и публикует Docker-образ в GHCR, а deploy-репозиторий содержит только `docker-compose.yml`, `.env.example` и инструкции запуска.
