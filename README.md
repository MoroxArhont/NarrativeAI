# Narrative AI

Веб-приложение интерактивных историй с регистрацией, SQLite и поддержкой OpenAI-совместимых моделей (Ollama, LM Studio и внешний API).

## Требования

- Node.js 22 или новее
- npm
- Для локальной генерации: Ollama или LM Studio с запущенной моделью и включённым API-сервером

## Запуск без Docker (Windows / PowerShell)

```powershell
Copy-Item .env.example .env
npm install
npm start
```

Откройте http://localhost:3000.

Для разработки с автоматическим перезапуском: `npm run dev`.

## Настройка ИИ

Войдите в аккаунт → **Настройки ИИ**.

- Ollama: `http://127.0.0.1:11434/v1`
- LM Studio: `http://127.0.0.1:1234/v1`

Укажите точное имя модели, доступное в выбранном приложении. В Ollama список можно посмотреть командой `ollama list`. В LM Studio запустите Local Server.

Для внешнего OpenAI-совместимого API укажите его Base URL и добавьте `AI_API_KEY` в `.env`. Ключ хранится только на сервере.

## Запуск через Docker Desktop

1. Скопируйте `.env.example` в `.env`.
2. Замените `SESSION_SECRET` на длинную случайную строку. Для локального запуска оставьте `COOKIE_SECURE=false`; при публикации за HTTPS-прокси установите `COOKIE_SECURE=true`.
3. В PowerShell выполните:

```powershell
docker compose up --build -d
```

4. Откройте http://localhost:3000.

В настройках ИИ внутри Docker используйте адреса:

- Ollama: `http://host.docker.internal:11434/v1`
- LM Studio: `http://host.docker.internal:1234/v1`

В приложениях Ollama/LM Studio сервер должен принимать подключения с хоста. Если соединение из контейнера не проходит, проверьте настройки сетевого доступа приложения и брандмауэр Windows.

Остановка: `docker compose down`. Данные SQLite сохраняются в `./data`.

## Возможности версии 2.0

- Регистрация, вход, выход и SQLite-сессии; пароли хранятся в виде bcrypt-хеша.
- Редактор истории: мир и завязка, характеристики главного героя, дополнительные персонажи, локации, события и факты канона.
- Необязательное первое сообщение повествователя: если оно заполнено, отображается первым; если пустое, игрок начинает сам.
- Обложка истории, аватар профиля и пользовательский фон чата (PNG/JPG/WebP до 2 МБ).
- Профиль истории вынесен отдельно из окна чата.
- Два этапа генерации: ИИ-режиссёр формирует план и ограничения, ИИ-повествователь пишет художественный ответ.
- Настройки моделей Режиссёра и Повествователя, контекст, температура/креативность, стиль, длина ответа и поведенческие переключатели.
- Для Ollama используется её нативный `/api/chat`, чтобы применять `num_ctx`, `num_predict`, `temperature`, `top_p` и `repeat_penalty`. LM Studio и внешние совместимые API используют `/v1/chat/completions`.
- Миграции SQLite добавляют новые поля в существующую базу без удаления старых аккаунтов и историй.

## Важные ограничения

- Это учебный MVP, не готовый публичный сервис. Перед публикацией добавьте HTTPS, CSRF-защиту, резервное копирование и более строгие ограничения сетевых адресов для внешних API.
- Сброс пароля, подтверждение почты, публичный каталог, совместное редактирование и потоковая генерация пока не реализованы.
- Изображения пока хранятся как data URL в SQLite; для большого числа пользователей лучше перенести их в файловое или объектное хранилище.
- ИИ-режиссёр снижает риск сюжетных противоречий, но не гарантирует абсолютную точность: результат зависит от выбранной модели и полноты введённого канона.
- При двух включённых моделях запросы выполняются последовательно, поэтому генерация будет медленнее, чем при одном ИИ.
