# Состояние проекта NarrativeAI 3.0

## Подключено
- Supabase Auth: регистрация, вход, проверка пользователя и обновление access token.
- PostgreSQL: профили, истории, сообщения, персонажи, локации, события и настройки ИИ.
- RLS: пользовательские записи ограничены владельцем.
- Supabase Storage: аватары, обложки и фоны чатов; в БД сохраняются пути файлов.
- Существующий интерфейс и генерация историй сохранены.
- Внешний ключ модели остаётся только на сервере в `AI_API_KEY`.

## Важно перед эксплуатацией
- В `.env` должны быть заданы `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.
- В Supabase должен быть включён Email/Password; поведение подтверждения почты зависит от настроек проекта.
- SQLite больше не используется. Старые локальные данные автоматически не переносятся.
- Нужна проверка полного сценария на реальном аккаунте: регистрация, вход, CRUD истории, Storage, генерация, изоляция двух пользователей.

## Структура
- `server.js` — Express API и интеграция Supabase REST/Auth/Storage.
- `public/` — интерфейс приложения.
- `supabase/migrations/` — SQL-схема и политики доступа.
- `deploy/` — Docker и инструкции запуска.
